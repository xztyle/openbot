### Changed

- An agent's settings panel uses the same design as the Settings page. Its settings are in titled
  groups: Identity, Where it works, Model and cost, Access and tools, Status, Performance, Memory
  and Settings history. Each setting has a label and a line that says what it does.
- Switches and choices in the panel save at once. The name, title, instructions, role and channel
  focus save with one save bar, which shows only while there is a change, with Save and Reset.
- "Forget what it learned in this chat" lists what the agent loses and asks first.
- A confirmation with a long button label no longer pushes Cancel off the screen on a phone.
