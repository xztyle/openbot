### Added

- Atelier workspace themes: Craft Studio (the default), Modern Atelier and Riso Press, each in
  light and dark. The server owner chooses the theme in Server settings > Workspace > Appearance;
  each person keeps their own light, dark or system choice.
- Agents show as Atelier faces in every list, chat, mention and chart: five families (portrait,
  sketch, flat, clay, character), a hat for the agent's role, and a face that works, talks, waits,
  fails or smiles with the agent. The owner chooses the default family and skin tone; each agent
  can change its own face in its avatar editor. An uploaded photo stays.
- The app and the web client show the Atelier symbol, and the web app has the Atelier icons.
