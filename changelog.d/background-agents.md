### Added

- Background teammates. An agent marked as background stays out of your sidebar, agent pickers and unread counts, and still works with your other agents. Open them from "Background teammates" at the end of the sidebar, on desktop and in the web client. Turn the setting on or off in Agent settings, under Advanced. Agents can create helpers as background teammates, and those start with notifications off.
- A setting in Settings, General, for how many agents your agents can create in 24 hours.

### Changed

- Agents can now create any number of agents. Before, they could create 20 agents in 24 hours. To set a limit again, use the new setting.
