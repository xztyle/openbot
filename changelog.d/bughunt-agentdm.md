### Fixed

- In an agent's DM, Send works while the server reconnects or the agent restarts. The message shows
  as waiting, with Edit and Dismiss, and goes once the agent is ready, one time only. A provider that
  is not set up or needs an update still keeps Send off.
- While an agent works, its DM header keeps one row: "Why is this slow?" stood above the model and
  the other controls, which made the header twice as tall on a phone and pushed the controls out of
  it on a computer.
- On a phone, the status of a chat card ("Waiting for you") goes under the card's title, so the
  title no longer breaks a site's name in the middle.
