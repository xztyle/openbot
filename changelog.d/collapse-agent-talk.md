### Changed

- Show messages between agents in channels and threads as one line: the faces of the sender and
  the recipients and a short summary. Click or tap the line to read the full text. Answers and
  questions for people still show whole.
- Show several agents that work in one place as one line, such as "3 agents working". Open it to
  see each agent with its Stop button.
- Fold long agent messages to their first lines with "Show more", in channels, threads and agent
  chats. A fold never cuts through a code block or a table.
- Do not show the steps and tools of agent turns in channels and threads. Agent chats keep them.

### Added

- Add debug mode, per device: in Settings, in the phone's More tab, or with ⌘⇧D (Ctrl+Shift+D). It
  shows steps, messages between agents and long messages in full, with a "Debug" badge.
