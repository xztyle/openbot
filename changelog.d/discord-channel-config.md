### Added

- Configure each connected Discord server in Server settings > Connectors > Discord. Pick the agent
  that answers in the server, and for each text channel pick its own agent or keep the server
  default. Turn on "Answer every message" for a channel, and OpenBot answers there without a
  mention. Messages in that channel go to one ongoing conversation, until it has no new message for
  two hours. The Discord bot needs a Signal update for "Answer every message".
