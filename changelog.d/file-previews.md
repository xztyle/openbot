### Added

- Every file in a message now shows as a preview, never as text. A video shows its first frame and
  plays in the message. An audio file shows a player with its waveform. A PDF, a slide deck, a text
  document or a spreadsheet shows a picture of its first page.
- One viewer opens every file: pages with zoom, page steps and search for PDFs and documents, slides
  with a rail for decks, sheet tabs for spreadsheets, a folder tree for ZIP and TAR files (a file in
  it opens in the same viewer), a table for CSV, and rendered Markdown. The arrow keys or a sideways
  swipe go to the next file of the message; a swipe down closes the viewer.
- The host makes the previews of Office files, videos and audio itself, and keeps them. The files
  stay on the host.
- The right-click menu of a file offers Play, Open, Download, Copy link and Copy text, as the type
  allows.
- Messages accept MP4, WebM, M4A, WAV and OGG media, and TAR archives.
