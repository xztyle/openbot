### Fixed

- Let you scroll up while an answer streams. Before, a short move up was undone by the next
  streamed text, because the chat moved back to the bottom.
- Make a long chat in the web client smoother while an answer streams. Before, each streamed word
  drew every message of the chat again.
- Keep the older messages and the message that you found with search when the connection to a
  host comes back. Before, the chat showed only the latest messages again.
- Keep a queued message that you edit when you press Escape to close the list of choices of an input
  method, or in another field of the page.
- Use less processor time for a long chat with many event check messages.
