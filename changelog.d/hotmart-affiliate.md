### Added

- The Hotmart helper reads the affiliate side. `affiliate-stats` gives, for each course sold as an
  affiliate, the sales, what buyers paid, the commission earned, refunds and chargebacks, sorted by
  commission. `affiliate-products` lists the courses sold as an affiliate. Agents can now send the
  daily stats per course. Hotmart has no API for affiliation requests, so these stay in the Hotmart
  app.

### Changed

- When a Hotmart credential is missing, the helper names each missing value and how to save it.
