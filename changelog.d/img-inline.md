### Fixed

- An image that you paste, drop or attach in a chat with an agent now shows as an image in your
  sent message, as an agent's image does, at any size: a large screenshot shows from a small copy,
  and the viewer opens the original. Right-click or a long press on it offers Copy image and
  Annotate. Images in a teammate's message to an agent show the same way.
- A pasted or attached file no longer puts a "@file name" chip in the text of the message. The file
  goes in the row of files over the message box, and the text keeps only your words. Older messages
  with such a chip show without it; the stored message does not change.
- In the web app, an image in the row of files over the message box opens in the image editor.
