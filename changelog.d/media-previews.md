### Changed

- The browser client shows images in a message inline, in a grid with their own shape, and opens them in the image viewer with zoom, swipe and a download. A large PNG or JPEG comes as a small copy that the host makes; the viewer reads the original. Images that the browser read once show again at once.
- Open on a file in a channel or a direct message shows the file in a viewer over the app: a PDF, text, code, CSV, audio and video. The viewer opens at once and says that the file is on its way. Download says that it started.
- On a phone, a drag down closes the image viewer.

### Fixed

- Artifact thumbnails in the browser client: the request for the image was refused before it left the browser.
