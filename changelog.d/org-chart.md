### Added

- Add an org chart to the workspace. It shows the agents of the space on a canvas, under the agent
  they report to, and shows which agents work now, wait for you or failed. Select a card to see what
  the agent does, open its chat or change its manager. Drag a card onto another card to change who
  it reports to. An agent reports to the agent that created it until you or an agent change it, and
  an agent can change the manager of a teammate with `update_profile`.
