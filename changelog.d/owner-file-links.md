### Fixed


- When an agent tells the owner about a file ("it is in the shared folder as copy-a.txt") and does not
  attach it, Atelier attaches it: in an answer to the owner, in a message to the owner, and next to a
  question or approval card. Only files of the agent's workspace and its space's shared folder, at most
  ten, never a hidden file or a key.
- Every file in a message shows its preview under the text, also one that the text names.
- A file name, a path or a folder in a message opens in the file viewer on the computer, the web and
  the phone. A folder opens as a list whose files open in the same viewer. A file that you may not see
  shows one plain sentence; a teammate opens only the files of the spaces they belong to.
