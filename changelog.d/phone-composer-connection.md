### Fixed

- On a phone with a weak connection, the message box of a channel or thread no longer stops taking
  keys while the app reconnects. A message sent while the server is away waits under the
  conversation as not sent yet, survives a reload, and goes once, in order, when the connection is
  back; one the server refuses offers Retry, Edit and Delete. Sending to an agent waits for the
  connection instead of failing.
- On an iPhone, "Attach image" and "Add context" in the + menu open the photo and file chooser again.
