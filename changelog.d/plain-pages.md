### Added

- Motion pages, tickets, comments and lists that are for the owner get a version in plain words. Atelier
  writes it with the cheap model, checks that every number, amount, date and decision is still there,
  and keeps it up to date when the agent text changes. Motion shows it as "Vista para personas".
- A Motion link that an agent shares with the owner shows the plain version in the chat preview.
- Motion human views are written four at a time, bounded, in the pass and the backfill.
- The plain version of a Motion page is now short: the current state only, a decision box on top
  (verdict, what you must do, key numbers, what is left), the evidence in sections you can open, and
  tables in place of long text. A long dossier shows at most about 900 words; every number stays.
