### Fixed

- A key or a password is hidden in every channel message the host stores, not only in what the message box sends. A message from Discord, from an access link or from an older app, an edit, and an agent's answer that quotes a key saved in Secrets now keep a short marker in its place, so the search, the previews, the push text, the Discord mirror and the other agents never read it. In an agent's answer only key shapes and saved values count, so its code that names a password stays.
