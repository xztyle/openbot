### Removed

- Server switching. Atelier runs on the one server that it is deployed to. The server rail, the server list and "Add a server" in the server menu, the server layout choice, the Ctrl/Cmd+1–9 server shortcuts, the server list in the phone's space switcher, and "Switch to this server" in Server settings are gone. The server menu now holds the actions of the host: mute, notifications, settings and the hosted server actions.
