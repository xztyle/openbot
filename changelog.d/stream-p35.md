### Added

- Organize the workspace sidebar as in Slack. Star a conversation to put it in Starred, make your own
  sections and move channels, DMs and agents into them from their menu or by dragging. Each section
  sorts in your order, by name, by recent activity or by priority, and can show only unread
  conversations or only mentions. Your sections, Starred and these choices follow your account to
  each computer and browser.
- A pencil shows on a conversation that has a message you did not send.
- Drafts & sent lists your unsent drafts, which you can open or delete, and the messages you sent,
  newest first. A sent message opens at its place in the conversation.
- Edit a message in place on a computer, as in Slack: Enter saves, Escape cancels, and an empty edit
  asks to delete the message. ↑ in an empty message box edits your last message. On a phone the edit
  stays in the message box.
- Type `:` and two letters of a short code to add an emoji, such as `:tada`.
- Quote and code block buttons in the formatting toolbar, with ⌘⇧9 and ⌘⌥⇧C. Enter inside a code
  block adds a line. The toolbar remembers whether you show it.

### Fixed

- Send every sidebar choice to the server. Before, the collapsed groups stayed on one computer, and a
  change could reach the server without the newest choice.
- "(edited)" now shows on an edited message with formatting, not only on plain text.
