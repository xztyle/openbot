### Added

- An image editor in the chat, on a computer and on a phone. "Annotate" in the image viewer, or a
  tap on an image in the message box, opens it: pen, arrow, rectangle, ellipse, text, an area that
  hides private details, a crop, seven colours, undo and redo. "Send to agent" puts the edited image
  in the message box; on a pasted image, "Done" replaces it; "Save" downloads it. The original
  message never changes. On a phone, one finger draws and two zoom and pan; on a computer, P, A, R,
  E, T, B, C and M pick the tools and ⌘Z undoes.
