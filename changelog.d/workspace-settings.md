### Added

- Server settings have a Workspace section for owners and admins. Choose the answer mode that an
  agent gets when someone adds it to a channel, and the model, effort and time limit of the quick
  check that decides if an agent that reads every message answers. Changes wait for Save.
- Agent settings have an In channels group for owners and admins. Set the answer mode and the focus
  note that the agent gets when someone adds it to a channel.
